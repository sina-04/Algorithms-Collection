# Algorithms-Collection
This is a collection of famous and useful algorithms used in computer science and engineering problems

## Overview

This repository gathers a wide range of **optimization and problem-solving algorithms** — from exact mathematical approaches to nature-inspired metaheuristics. It’s designed as a learning and reference resource for students, researchers, and engineers interested in **operations research, computer science, and data-driven decision-making**.

The algorithms are grouped into three main categories:

---

### 🧮 Exact Algorithms

These algorithms guarantee finding the _optimal_ solution by systematically exploring the solution space.
They’re often used in mathematical optimization, linear programming, and combinatorial problems.

**Examples include:**

- Simplex Method
- Branch and Bound
- Branch and Cut
- Dynamic Programming
- Cutting Plane Method
- Branch and Price
- Network Simplex Algorithm
- Interior Point Method
- Hungarian Algorithm
- Dijkstra’s Algorithm

---

### ⚙️ Heuristic Algorithms

Heuristics focus on finding _good_ (but not necessarily optimal) solutions efficiently.
They rely on problem-specific rules or intuition to speed up computation for complex problems.

**Examples include:**

- Greedy Algorithm
- Nearest Neighbor Heuristic
- 2-opt and 3-opt
- Insertion Heuristic
- Savings Algorithm (Clarke & Wright)
- Local Search
- Hill Climbing
- GRASP (Greedy Randomized Adaptive Search Procedure)
- A\* Search
- Scheduling Heuristics (SPT, LPT, etc.)

---

### 🧠 Metaheuristic Algorithms

Metaheuristics are _high-level strategies_ that guide heuristics to explore the search space more effectively.
They are often inspired by **natural, physical, or social processes**, and are especially powerful for large-scale or NP-hard problems.

**Examples include:**

- Genetic Algorithm (GA)
- Simulated Annealing (SA)
- Tabu Search
- Ant Colony Optimization (ACO)
- Particle Swarm Optimization (PSO)
- Differential Evolution (DE)
- Artificial Bee Colony (ABC)
- Harmony Search (HS)
- Firefly Algorithm (FA)
- Cuckoo Search (CS)

---

### 🧩 Purpose

This project aims to provide:

- **Clean implementations** of each algorithm in Python (with comments and references).
- **Comparative insights** into their performance and use cases.
- A **structured reference** for learning optimization techniques systematically.
