# Algorithms Collection

> **Archived roadmap:** this repository contains a planning catalog only.
> It does not currently contain algorithm implementations, benchmarks, or
> runnable examples.

The original goal was to build a structured learning collection spanning
exact, heuristic, and metaheuristic optimization methods. The repository is
archived so that its current state is represented honestly while preserving
the roadmap for possible future work.

## Planned catalog

| Family | Candidate methods |
| --- | --- |
| Exact | Simplex, branch and bound, dynamic programming, Hungarian algorithm |
| Heuristic | Greedy construction, nearest neighbor, local search, 2-opt |
| Metaheuristic | Genetic algorithm, simulated annealing, tabu search, PSO |

Any future revival should add one method at a time with:

1. an explanation and mathematical assumptions;
2. a tested, importable implementation;
3. a reproducible example or benchmark;
4. references and complexity notes.

## Status

No implementation is currently available. For completed optimization work,
see [GAMS Optimization Portfolio](https://github.com/sina-04/GAMS-Optimization-Portfolio)
and [Computational Algorithms for Facilities Planning](https://github.com/sina-04/Computational-Algorithms-for-Facilities-Planning).
